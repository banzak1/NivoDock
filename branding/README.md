# NivoDock — identidade refinada

Slogan: **Seus jogos. Um só lugar.** Símbolo: N composto por duas peças em conexão, com um recorte diagonal entre elas.

Paleta: fundo `#101113`, superfície `#202023`, texto secundário `#A1A1AA`, texto principal `#F4F4F5`, assinatura `#9C90FF`, ação principal `#6957DB`. Use a versão branca sobre fundo escuro e a versão grafite sobre fundo claro; não dependa de cor para indicar seleção. Use a cor de assinatura com moderação: ação principal, seleção e foco. Texto branco sobre o botão `#6957DB` tem contraste calculado de 5,27:1. Mantenha área livre de pelo menos 1/4 da largura do símbolo.

Fontes: sistema (`Segoe UI`, Arial/sans-serif). Os logos SVG mantêm o texto editável e usam essa mesma pilha; podem renderizar com pequenas diferenças de fonte conforme o sistema. Não há arquivo de fonte de terceiros no pacote.

Originais em `public/brand/`: `icon.svg`, `mark.svg` (colorido), `mark-light.svg`, `mark-dark.svg`, `logo-light.svg`, `logo-dark.svg`. PNGs 16, 24, 32, 48, 64, 128, 256 e 512 pixels e ICO com sete resoluções. Guia visual: `public/brand/index.html`; prévia: `branding/preview.png`.

Exportação opcional: instale Playwright no ambiente de desenvolvimento e rode `node scripts/export-brand.cjs`. `PLAYWRIGHT_MODULE` e `CHROMIUM_PATH` permitem reutilizar uma instalação existente. Esses recursos não são necessários para usar nem empacotar os arquivos já exportados. A geometria foi desenhada em SVG e exportada pelo navegador, sem geração de imagens por IA.

Nome selecionado pelo usuário após busca pública preliminar; sem garantia de exclusividade ou registro de marca. A identidade não usa personagens nem logotipos de jogos. Edições comerciais futuras devem conservar a mesma marca principal.
